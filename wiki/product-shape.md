# Statmerica Product Shape

## Summary

Statmerica is currently a data-driven homepage prototype for comparing political administrations through economic and social metrics.

## Route Surface

The current App Router surface is small:

- `/` for the homepage and metrics dashboard
- `/about`
- `/data-sources`

This is a focused informational site shape rather than a full application with accounts, submissions, or live personalization.

## Main Experience

The homepage composition currently combines:

- a site header and hero
- a metrics dashboard
- supporting comparison and navigation components
- a site footer

The core interaction is selecting administrations or party-level views and exploring metric comparisons rather than reading long-form editorial content.

## Product Character

The repo currently feels closer to:

- a design/prototype for a political-economy comparison site
- a metrics dashboard backed by prefetched datasets
- a project that could become more relevant during election season

It does not yet read as a finished election product with a clearly settled editorial or campaign-season operating model.

## Important Context

The root `README.md` is still boilerplate from the v0 sync workflow and should not be treated as the real product description. The repo’s actual identity is clearer in the metrics, data files, and scripts than in the README.
